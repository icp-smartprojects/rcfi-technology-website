# RCFI Website V2

Professional RCFI Technology website built with Next.js.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3002](http://localhost:3002)

## Pages

| Route | Page |
|-------|------|
| `/` | Home |
| `/products/certysign` | CertySign |
| `/products/elano` | Elano |
| `/products/prezio` | Prezio |
| `/about` | About |
| `/contact` | Contact |

## Stack

- Next.js 14 (Pages Router)
- React 18
- Tailwind CSS
- Fonts: Archivo + Public Sans
